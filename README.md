# Dashboard Financeiro GEC

Painel financeiro conectado à planilha pelo Apps Script informado.

## Como abrir

Abra o arquivo `index.html` em um navegador ou publique esta pasta em qualquer hospedagem de arquivos estáticos (por exemplo, GitHub Pages, Netlify ou Vercel).

O painel consulta a fonte de dados automaticamente e oferece filtros por mês e classificação. Use o botão de atualização no canto superior direito para buscar os dados mais recentes.

> A fonte precisa permanecer publicada como aplicativo da Web com permissão de acesso para os usuários que abrirão o dashboard.
